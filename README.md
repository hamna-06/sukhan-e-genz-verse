# 🌟 Sukhan-e-GenZ Verse

**Sukhan-e-GenZ Verse** is a modern digital platform designed to bridge the gap between traditional Urdu poetry (Shayari) and Gen Z aesthetics. By combining the elegance of Nastaliq typography with contemporary UI/UX design, this app redefines how the younger generation interacts with, creates, and shares Urdu literature.

## ✨ Features

*   **🎨 Gen Z Aesthetic UI:** A vibrant, sleek, and highly engaging interface designed using modern design principles.
*   **✍️ Beautiful Nastaliq Typography:** Beautifully renders traditional Urdu text seamlessly on digital screens.
*   **⌨️ Phonetic Urdu Keyboard:** Built-in phonetic support making it incredibly easy for users to type in Urdu using standard English characters.
*   **✨ Aesthetic Converter:** Convert simple poetry text into visually stunning, shareable formats optimized for social media platforms like Instagram and TikTok.

---

## 🛠️ Tech Stack

*   **Frontend Framework:** React (with Vite / TanStack)
*   **Database & Backend:** Supabase
*   **Package Manager:** Bun
*   **Styling:** Tailwind CSS
